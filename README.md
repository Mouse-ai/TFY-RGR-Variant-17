# Теория формальных языков — РГР, вариант 17

Учебный проект на **C++17** по заданиям 1–12 из методички «ТФЯ. РГР.pdf». Одно приложение, отдельные запускаемые задания, переиспользуемые алгоритмы и автоматические тесты.

## Запуск

Нужны CMake 3.16+ и компилятор C++17 (GCC/Clang/MSVC). Открыть проект можно в CLion, VS Code с CMake Tools или Visual Studio.

```bash
cmake -S . -B build
cmake --build build
./build/rgr --task 5
./build/rgr --all
```

На Windows исполняемый файл может находиться в `build/Debug/rgr.exe` или `build/Release/rgr.exe` (в зависимости от генератора).

Параметры:

- `--task N`: одно задание (от 1 до 12).
- `--all`: все задания.
- `--limit N`: количество первых степеней для заданий 2–3, а для задания 1 — максимальная длина цепочки дополнения (1–5; по умолчанию 3).
- `--dot-dir DIR`: сохранить графы переходов и деревья в формате DOT.

Например:

```bash
./build/rgr --task 8 --dot-dir graphs
./build/rgr --all --limit 3 --dot-dir graphs
```

Если установлен Graphviz, преобразуйте DOT в PNG или SVG:

```bash
dot -Tpng graphs/task08_DFA.dot -o graphs/task08_DFA.png
dot -Tsvg graphs/task11_parse_tree.dot -o graphs/task11_parse_tree.svg
```

## Что делает каждое задание

| № | Реализация |
|---|---|
| 1 | Объединение, пересечение, разности, дополнение, конкатенации L1 и L2 |
| 2 | Положительная итерация и звезда Клини языка `{11}` |
| 3 | Грамматика типа 2 и вывод `a^(2n+3)` по продукциям |
| 4 | Контекстно-свободная грамматика для `a^k b^l c^m b^l a^k` |
| 5 | ДКА с пятью состояниями; таблица и DOT-граф |
| 6 | НКА с тремя состояниями; таблица и DOT-граф |
| 7 | Преобразование ДКА №5 в НКА (переходы как множества, ловушка) |
| 8 | Преобразование НКА №6 в ДКА методом подмножеств |
| 9 | Построение регулярной грамматики из ДКА №5 |
| 10 | Преобразование грамматики из условия в эквивалентный НКА |
| 11 | Минимальная цепочка, обычный и размеченный вывод, деревья и однозначность |
| 12 | Проверка простого предшествования и пояснение, почему 12(б) не выполняется |

## Уточнения по математике

- **Задание 1:** дополнение языка бесконечно. Поэтому выводятся правильная формула и *конечная выборка* всех цепочек длиной до заданной границы. Программа не утверждает, что выборка — всё дополнение.
- **Задание 2:** `L+` и `L*` бесконечны; выводятся только первые несколько степеней.
- **Задание 5:** в условии ровно 5 состояний. Для этого языка построен **частичный ДКА**. Если требуется полная функция переходов, добавляется шестое ловушечное состояние.
- **Задание 7:** любой ДКА — частный случай НКА. Преобразование использует одноэлементные множества переходов; дополнительная ловушка воспроизводит образец оформления из тетради, но не меняет язык.
- **Задание 8:** `EMPTY` — отдельное ловушечное состояние ДКА, полученное из пустого множества при методе подмножеств.
- **Задание 12:** у правил `S -> a` и `A -> a` совпадают правые части, так что грамматика **не является грамматикой простого предшествования**. По условию анализатор строится только при положительном результате, поэтому 12(б) не реализуется.
- Для удобства вывода используется слово `lambda` в обозначении пустой цепочки.

## Тестирование

```bash
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

Тесты работают и в сборке Release. Они проверяют операции над языками, выводы грамматик и эквивалентность автоматов. Для заданий 5, 7, 9 перебираются все слова над `{a,b,c}` длины до 8, для заданий 6, 8 — все слова над `{0,x}` длины до 10.
