# РГР по теории формальных языков — вариант 17

Простая учебная программа на **C++17** для всех 12 заданий.

Здесь нет CMake, CI/CD, Graphviz и сложной архитектуры: только обычные `.cpp`, функции, циклы, строки, множества и таблицы переходов. Код разделён на несколько файлов, чтобы не смешивать все задания в одном месте.

## Файлы

- `main.cpp` — выбор номера задания (1–12).
- `tasks.h` — объявления функций `task1()` … `task12()`.
- `tasks_1_4.cpp` — операции над языками и грамматики.
- `tasks_5_10.cpp` — ДКА, НКА и преобразования.
- `tasks_11_12.cpp` — выводы и проверка простого предшествования.

## Компиляция и запуск

Нужен компилятор с поддержкой C++17 (например, `g++`). Открой терминал в папке проекта:

```bash
g++ -std=c++17 main.cpp tasks_1_4.cpp tasks_5_10.cpp tasks_11_12.cpp -o rgr
```

Запусти выбранное задание:

```bash
./rgr 5
```

Или просто `./rgr`, а затем введи номер от 1 до 12. В Windows запускается `rgr.exe`.

## Как устроены задания

| Задания | Что происходит |
|---|---|
| 1–2 | Операции над `set<string>`, конкатенации и итерации |
| 3–4 | Проверка класса грамматики и вывод цепочек по правилам |
| 5–6 | Создание ДКА/НКА, таблицы переходов, проверка слов |
| 7 | Преобразование ДКА №5 в НКА с ловушкой |
| 8 | Метод подмножеств для преобразования НКА №6 в ДКА |
| 9 | Преобразование переходов ДКА №5 в регулярные продукции |
| 10 | Преобразование правил грамматики варианта 17 в НКА |
| 11 | Поиск кратчайших цепочек перебором правил, все выводы и вычисленные деревья |
| 12 | Проверка обратимости, вычисление FIRST/LAST и таблицы отношений |

## Важные ограничения

- Дополнение в задании 1 и итерации в задании 2 бесконечны, поэтому выводятся только конечные примеры (до длины 3 и первые 5 степеней).
- Для задания 5 применяется **частичный ДКА** с 5 состояниями по условию. Полный автомат потребует ещё ловушечного состояния.
- В задании 8 множества состояний из НКА становятся состояниями ДКА, включая пустое множество (ловушка).
- В задании 11 используется ограниченный перебор правил (до 12 терминалов и 22 шагов), а в задании 12 таблица отношений рассчитывается по грамматике. Отсутствие неоднозначности в конечной проверке **не доказывает** однозначность всего бесконечного языка. Задача установления неоднозначности произвольной контекстно-свободной грамматики в общем случае неразрешима.
- Код рассчитан на учебное объяснение: некоторые данные варианта специально записаны прямо в соответствующих функциях.

**Как рассказать на защите:** сначала открой `main.cpp`, затем файл нужного задания и объясни, какие данные он берёт, какие циклы выполняет и почему выдаёт именно этот результат.
